# LUMIO

Εξατομικευμένα εκπαιδευτικά παιχνίδια, φύλλα εργασίας, δραστηριότητες και προγράμματα για κάθε μαθητή.

## Ανέβασμα στο GitHub Pages
1. Αποθετήριο στο aglentzakis-dot (π.χ. το υπάρχον `Paidagogos-AI` ή νέο `LUMIO`).
2. Ανέβασε όλα τα αρχεία αυτού του φακέλου όπως είναι (αντικαθιστώντας τα παλιά).
3. Settings → Pages → Branch: main / root → Save.

Αν ανέβει στο ίδιο αποθετήριο με την προηγούμενη έκδοση, οι υπάρχοντες λογαριασμοί και τα δεδομένα διατηρούνται.

## Αναβάθμιση
Η εφαρμογή διαβάζει το `version.json` και αναβαθμίζεται μόνη της.

## Email ανάκτησης
Ρυθμίσεις → Αποστολή email: στοιχεία EmailJS (δωρεάν πρόγραμμα) και πρότυπο μηνύματος.

## Ταμείο
Τα αρχεία tameio.html και tameio.js είναι ο κώδικας της εφαρμογής «Ταμεία», προσαρμοσμένος για το LUMIO (δικά του δεδομένα ανά λογαριασμό, μίνιμαλ εικονίδια, οι πληρωμένες συνεδρίες περνούν στην «Εργασία»). Ανεβαίνουν μαζί με τα υπόλοιπα.
